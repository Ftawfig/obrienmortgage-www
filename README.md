# www.obrienmortgage.ca redirect

Static pages served by GitHub Pages at `www.obrienmortgage.ca`. Each one forwards the visitor to the same path on
`https://obrienmortgage.ca`, where the real site lives. Unknown paths use `404.html`, which forwards too.

Do not delete this repository or its `CNAME` file while `www.obrienmortgage.ca` points here.
